# 📋 Lead Management CRM

A full-stack Lead Management CRM application built with React.js, Node.js, Express.js, and MongoDB Atlas.

---

## 🚀 Live Demo

- **Frontend:** [https://your-app.vercel.app](https://lead-management-crm-chi.vercel.app)
- **Backend API:** [https://your-api.onrender.com](https://lead-management-crm-akql.onrender.com)

---

## ✨ Features

- ➕ Add new leads
- 📋 View all leads in a table
- ✏️ Edit existing leads
- 🗑️ Delete leads
- 🔍 Search leads by name, email, or company
- 🎯 Filter leads by status
- 🏷️ Lead status tracking (New → Contacted → Qualified → Converted → Lost)

## ⚙️ Local Setup Instructions

### Prerequisites

Make sure you have these installed:
- [Node.js](https://nodejs.org/) (v18 or above)
- [Git](https://git-scm.com/)
- A [MongoDB Atlas](https://cloud.mongodb.com) account (free tier works)

---

### Step 1 — Clone the Repository

```bash
git clone https://github.com/vanshita-vilas-parab/lead-management-crm.git
cd lead-management-crm
```

---

### Step 2 — Setup Backend

```bash
cd backend
npm install
```

Create a `.env` file inside the `backend/` folder:

```env
MONGO_URI=your_mongodb_atlas_connection_string
PORT=8000
```

> **How to get MongoDB URI:**
> 1. Go to [MongoDB Atlas](https://cloud.mongodb.com)
> 2. Click your Cluster → Connect → Drivers
> 3. Copy the connection string
> 4. Replace `<password>` with your actual password

Start the backend server:

```bash
npm run dev
```

You should see:
```
✅ MongoDB connected
🚀 Server running on port 8000
```

---

### Step 3 — Setup Frontend

Open a new terminal tab:

```bash
cd frontend
npm install
npm run dev
```

Open your browser at:
```
http://localhost:5173
```

## 🌐 API Endpoints

Base URL: `[http://localhost:8000/api/leads](https://lead-management-crm-akql.onrender.com/api/leads)`

| Method | Endpoint       | Description          |
|--------|---------------|----------------------|
| GET    | `/`           | Get all leads        |
| GET    | `/?search=x`  | Search leads         |
| GET    | `/?status=New`| Filter by status     |
| GET    | `/:id`        | Get single lead      |
| POST   | `/`           | Create new lead      |
| PUT    | `/:id`        | Update lead          |
| DELETE | `/:id`        | Delete lead          |

## 📊 Lead Fields

| Field       | Type   | Required | Notes                                          |
|-------------|--------|----------|------------------------------------------------|
| name        | String | ✅ Yes   | Lead's full name                               |
| email       | String | ✅ Yes   | Must be unique                                 |
| phone       | String | No       | Contact number                                 |
| company     | String | No       | Company name                                   |
| status      | String | No       | New / Contacted / Qualified / Converted / Lost |
| notes       | String | No       | Additional notes                               |
| createdAt   | Date   | Auto     | Auto-generated by MongoDB                      |

## 🚀 Deployment

### Backend — Render

1. Go to [render.com](https://render.com) → New Web Service
2. Connect your GitHub repo
3. Set:
   - **Root Directory:** `backend`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
4. Add environment variables:
   - `MONGO_URI` = your MongoDB Atlas URI
   - `PORT` = 8000
5. Deploy

### Frontend — Vercel

1. Go to [vercel.com](https://vercel.com) → New Project
2. Import your GitHub repo
3. Set **Root Directory** to `frontend`
4. Deploy

> ⚠️ After deploying backend, update `frontend/src/api/leadApi.js` with your Render URL before deploying frontend.

## 🔧 Common Issues & Fixes

| Issue | Fix |
|-------|-----|
| `Port 5000 blocked on Mac` | Change PORT to 8000 in `.env` |
| `MongoDB connection failed` | Whitelist `0.0.0.0/0` in MongoDB Atlas Network Access |
| `Network Error` on frontend | Make sure backend server is running |
| `Email already exists` | Each lead must have a unique email |
| `Permission denied` on git push | Check GitHub credentials / Personal Access Token |
